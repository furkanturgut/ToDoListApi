# To-Do List API

### Overview
This is a simple To-Do List API where users can create, read, update, and delete tasks, with the ability to filter tasks by status. Authentication is required for accessing task data.

### Features
- CRUD operations (Create, Read, Update, Delete) for tasks
- Basic Authentication for secure access
- Task filtering by status

### Technologies Used
- C#
- .NET Core
- Entity Framework Core
- Basic Authentication Middleware
